# PiUI 前端兼容重写计划

## 状态与目标

- 审计基线：`03af7883`，审计时工作区干净。
- 已完成：四路只读审计及第一批 A / B / H 的代码集成与自动化回归。全仓既有门禁、完整视觉矩阵与真机验收未关闭；尚未取得真机性能基线。
- 用户已批准：保存计划，开始第一轮 A / B / H。后续阶段按验收门推进，不将第一轮称为全面重写完成。
- 总原则：**静止时仍是现在的 PiUI，操作路径相同；状态变化更连贯，流式输出与触屏操作更流畅。**
- 方法：行为兼容的分层重写，全面覆盖 UI，但不要求每个文件都重写，不清空仓库、不换框架。
- 本文件记录计划；执行证据与未完成项记录在 `docs/FRONTEND_REWRITE_ROUND_1.md`。未运行或未通过的项目不得写成通过。

## 1. 不变项与技术边界

### 视觉与交互契约

保留现有颜色、字体、字号、圆角、间距、密度、图标、主题、自定义 CSS、字号缩放和毛玻璃开关。使用现有 `index.css` token，不引入新的视觉语言。依据 `docs/UI_SYNC_POLICY.md` 判定：本轮是内部重构和原有状态反馈完善，不重新设计 OCUI 等价界面；无明确等价上游实现时按判据 3 处理，提交注明判据。

保留发送、中止、steer / followUp、队列编辑、undo / redo、fork、模型切换、附件、命令、提及、快捷键、权限与扩展问答。保留草稿、展开状态、滚动位置、布局、设置和多服务器隔离。

保留 Android 输入法合成、键盘避让、安全区、返回键栈、前后台恢复及已有手势与距离阈值。不得把底部原生 padding 再叠加成网页 safe area。保留滚动期毛玻璃降级、分页静止态 2D、输入区淡出期间实色回退。

保留项目授权、HTML sandbox、Markdown 清理和扩展权限边界。禁止重引入 OpenCode transport、WSL、Docker 或桌面运行时概念。

### 保留与可替换层

- 保留 React 19、Tailwind 4、Vite 8、motion/mini、TanStack 虚拟列表、Shiki Worker、marked / morphdom 及既有增量 DOM 路径。
- `src/pi` 仍是唯一命令 / 事件出口。协议、原生桥、持久化键与 store 公共接口不在第一轮改写范围。
- 保持 `App -> features/pi-chat -> features/chat / message` 分层，不绕过 ESLint 导入门禁。
- 可改写组件内部结构、控制 hooks、订阅粒度、派生计算、缓存、测量调度、动效实现与懒加载边界。
- 不把拆文件当性能成果；必须用计算耗时、重渲染次数、布局成本或内存证明收益。

## 3. 动效规格

增加的是状态反馈覆盖面，不是动画数量或操作延迟。以下为普通模式初始规格，待真机验证后冻结；有理由的已有特殊时序不机械替换。

| 场景                       | 方案                                               | 时长      |
| -------------------------- | -------------------------------------------------- | --------- |
| 按钮 / 图标按钮            | 触屏按压与释放，键盘不等待                         | 100–140ms |
| 下拉 / 选择器 / 浮层       | 触发源原点，轻位移与透明度；不新增高频键盘打开动效 | 150–180ms |
| 弹窗 / 权限 / 问答         | 遮罩与内容分层，退出可中断                         | 180–220ms |
| 侧栏 / 现有滑动面板        | 拖动跟手、释放收尾；不改关闭阈值                   | 220–260ms |
| 工具 / 思考 / 详情         | 展开与箭头同步，保留锚点                           | 180–260ms |
| 附件 / 队列 / 输入附属面板 | 增删与位置变化连续                                 | 160–200ms |
| Toast                      | 入场、更新、退出与让位一致                         | 160–200ms |
| 执行状态                   | running 到 completed / error 的图标过渡            | 120–160ms |

规则：

- 扩展既有常量，而非另建不相通的动效系统；CSS 和 JS 使用同一组语义值。
- 普通浮层优先 transform / opacity，显式列出过渡属性，不使用 transition-all。
- 常规 ease-out 可用 `cubic-bezier(0.23, 1, 0.32, 1)`；面板沿用已有 drawer 曲线 `cubic-bezier(0.32, 0.72, 0, 1)`。不为统一而改掉有明确用途的 linear。
- 中断从当前状态继续；卸载取消动画和定时器；关闭后不残留焦点、遮罩或点击锁。
- 减少动态效果覆盖 CSS、WAAPI、JS，并响应偏好变化；去掉位移 / 缩放，保留必要反馈，不空等原动画时长。
- 不给流式 token、历史列表重挂载或高频键盘操作增加动画；不做大范围 stagger。
- 不动画 blur，不常驻堆叠 will-change，不在 Android 毛玻璃祖先随意增加合成层。
- 披露内容需要真实布局高度；不得机械用 scale 代替 height。SmoothHeight、Android 展开、entry-grow 完成标记与滚动锁先保留，替换须有等价测试和真机依据。

## 4. 阶段与验收门

### 阶段 0：冻结与基线

建立页面 / 状态清单、固定数据截图和关键操作录像、旧实现行为契约、真机性能场景与质量门禁结果。记录硬件、Android / WebView、构建模式。先证明测试在旧实现成立，失败项单列。没有基线不报告性能提升。

### 阶段 1：基础层与控制容器（本次第一轮）

A 统一基础动效参数、入退场与中断清理、减少动态效果；B 将 PiChatPane 控制逻辑按边界抽取；H 补齐行为契约并建立验证记录。结构变化和动效变化分开提交。

第一批明确范围：

- A：usePresence / useDelayedRender 生命周期、共享 motion 参数、Button / IconButton / MenuItem 的显式过渡与 reduced-motion；新增对应单测。不改 Dialog 手势、useCompositorExpand / SmoothHeight 的平台逻辑，不批量迁移所有动效。
- B：优先抽取队列控制和扩展编辑器桥接（必要时分成两个小提交）；保留 clear-then-replay、500ms 镜像防抖、发送前清空镜像、服务器 / 会话切换清理与输入恢复语义。不得顺手重写 undo / fork 或数据层。
- H：旧实现基线、useBackClose 契约测试、Tauri viewport 分支测试、自动化覆盖与未验证清单。功能单元测试由 A / B 各自负责，H 不同时编辑这些测试。
- 主代理：计划与执行记录、共享配置 / 行数基线、代码审查、集成与门禁。

完成标准：新增行为测试通过，相关类型与 lint 检查通过，既有测试不回退；静态样式不漂移；命令副作用顺序相同。未完成真机或既有全仓门禁仍失败时，明确标为未验收，不称为全量通过。

### 阶段 2：聊天核心链路

C 时间线 / 虚拟化、D 消息 / 富文本、E 输入系统并行。打通输入、发送、流式输出、工具调用、结束和历史恢复。保留行 key、上滚停止跟随、prepend 锚点、折叠状态和 IME 行为。

优先优化重复扫描与不稳定订阅；测量确认后才扩大 Markdown 增量解析或修改 Worker 传输。HTML artifact 增量协议属高风险，后置且保留 sandbox。

### 阶段 3：其他界面

F 导航 / 设置与 G 工作区面板覆盖剩余界面。应用外壳与移动 pager 最后整合，依赖聊天区与输入区尺寸契约稳定。异常、空状态、权限、重连与多服务器不漏项。

### 阶段 4：真机调优与全量回归

流式同时滚动、展开、切面板；快速开关；中文 IME；键盘 / 返回 / 横竖屏；主题、字号与 glass；分屏焦点、多服务器同 ID 会话、前后台恢复；长时间缓存与内存。每个问题按文件归属回到责任代理修复。

### 阶段 5：切换与清理

必要时用内部新旧渲染器开关对照，同一时刻只挂载一套，避免双订阅和副作用。分模块验收后切换，保留小提交回退点。删除旧实现另列清单并取得确认；不批量删除、不 reset --hard、不 force push，不清用户数据。

## 5. 子代理分工与调度

1 主代理 + 8 专项角色，最多同时运行 4 个子代理。角色不是同时启动数量。各工作包在启动时登记精确文件白名单；以下路径以 `packages/app/src/` 为基准。

| 角色         | 职责 / 文件边界                                                                        |
| ------------ | -------------------------------------------------------------------------------------- |
| 主代理       | 契约、跨模块接口、依赖配置、行数基线、集成与最终验收；Pi store / 协议 / 原生桥默认冻结 |
| A 动效基础   | index.css、相关 constants、动效 hooks、components/ui；不改业务 / 手势语义              |
| B 运行时容器 | features/pi-chat；发送 / 队列 / fork / undo / mirror 兼容抽取                          |
| C 时间线     | ChatArea、chatPageModel、chatAreaVisibility、相关工具、virtual                         |
| D 消息富文本 | features/message、Markdown / CodeBlock、Shiki client / worker；工具仍走 registry       |
| E 输入       | InputBox、chat/input、attachment / mention / slash-command                             |
| F 导航设置   | App、Sidebar / sidebar、sessions、settings；pager 最后                                 |
| G 工作区     | FileExplorer、DiffViewer、SessionChangesPanel、Terminal、扩展面板                      |
| H 验证       | 集成测试、夹具、截图 / 性能脚本、验证记录；不改 A / B 所属测试                         |

调度：A+B+H → C+D+E+H → F+G+H → 主代理+H+责任代理。

协作约束：独立分支 / worktree；一文件一写入者；接口先冻结；跨界通过主代理；各自维护本模块单测，H 负责跨模块；交付提交、范围、验证、风险和未完成项。出现非预期文件变化立即停下，不碰用户脏文件。禁止用删断言、降低覆盖率或自动接受截图漂移换绿。

## 6. 验证与性能预算

### 行为契约

- 时间线顺序、过程壳归属、Working / Worked、隐藏条目、稳定 key。
- 贴底滞回、上滚停止追随、历史加载锚点、折叠后不跳底。
- prompt / steer / followUp、中止、队列 clear-then-replay、首条消息模型与 thinking 设置顺序。
- 编辑器镜像不覆盖本地输入；真实 extension set / paste 保留；发送清镜像；失败恢复草稿。
- fork 与 undo / redo 树导航、快捷键注册、会话 / 服务器隔离。
- 输入折叠与底部占位不变量、IME Enter 不误提交、跨输入焦点与键盘 inset。
- useBackClose 嵌套栈、快速关闭、卸载清理；问答全屏切换保留输入。
- 动效快速反转 / 中断 / 卸载，reduced-motion 初始与运行中切换。
- HTML sandbox、清理、权限、项目授权不变。

### 视觉

固定数据、字体、视口、浏览器版本、主题 / 字号 / glass 下对照静态截图；动态过程单独录像 / 逐帧检查。无未经确认的布局、颜色、字号或密度变化，不自动更新基线接受漂移。

### 性能

以下是初始目标，不是已有成果；阶段 0 真机实测后冻结：

| 指标                       | 初始目标                      |
| -------------------------- | ----------------------------- |
| 核心流式压力场景主线程耗时 | 比基线减少至少 25%            |
| 普通本地交互到下一次绘制   | P95 <= 50ms，不含网络等待     |
| 60Hz 关键交互掉帧率        | < 5%                          |
| 不变历史消息               | 不因普通 token 更新重解析正文 |
| 首屏 JS / 启动时间         | 不退化                        |
| 长时间会话                 | 缓存有界，无持续内存增长      |

固定场景：1000 条时间线、500 行代码、2000 行 diff、流式 60 秒、滚动 / 工具展开 / 会话切换竞争、HTML artifact、30 分钟使用。复用 `?piuiPerf=1` 埋点，记录解析、timeline、测量、组件 commit、Worker 字节、DOM 与缓存数量。控制埋点自身成本。桌面 CPU throttle 仅作辅助，不替代真机。

### 工程门禁

最终必须通过 `npm run validate`、`npm run smoke:timeline`、`npm run smoke:android-ui`，加新增视觉 / 中断 / 真机验收。单模块使用 `npm run test:run -w @piui/app -- --maxWorkers=1 <测试文件>`。配置 LSP 可用时运行诊断；不可用如实记录配置问题，不冒称无诊断。

新 TS / TSX 不超过 1000 行；超限既有文件只减不增；下降后同步基线。覆盖率阈值只升不降。Chromium 冒烟通过不代表 Android IME、安全区、系统返回和帧稳定性已通过。
